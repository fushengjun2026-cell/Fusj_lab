# Russian text font

`pt-serif-regular.woff` is PT Serif Regular by ParaType, converted losslessly from
[Google Fonts' original TTF](https://github.com/google/fonts/blob/main/ofl/ptserif/PT_Serif-Web-Regular.ttf)
to WOFF without changing glyphs or layout tables. The complete font is bundled
so Cyrillic letters and combining stress marks use the same font on every device.
